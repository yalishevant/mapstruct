# KSP Demo: MapStruct with Kotlin Symbol Processing

This demo project demonstrates **MapStruct running with KSP (Kotlin Symbol Processing)** backend instead of KAPT.

## Status

✅ **Working**: MapStruct KSP processor successfully generates Java mapper implementations
⚠️ **Limited**: Kotlin property mapping not yet implemented (mappers generate but fields are not copied)

## Related Components

This demo is part of MapStruct KSP integration:

- **`processor-ksp/`** — MapStruct KSP processor module (Maven, full MapStruct architecture integration)
- **`ksp-demo/`** — Demo project using the KSP processor (Gradle)

## What This Demo Shows

- **Real MapStruct** running with KSP backend (not a standalone processor)
- Reads Kotlin `@Mapper` interfaces using KSP API
- Generates Java mapper implementations using MapStruct's code generation
- Compiles successfully with proper `public` method modifiers

## How It Works

### 1. Define Kotlin Models

```kotlin
// Source - Kotlin data class
data class Person(
    val firstName: String,
    val lastName: String,
    val age: Int
)

// Target - mutable class (needs setters for Java-style mapping)
class PersonDto {
    var firstName: String = ""
    var lastName: String = ""
    var age: Int = 0
}
```

### 2. Define Mapper Interface

```kotlin
@Mapper
interface PersonMapper {
    fun toDto(person: Person): PersonDto
}

// With field renaming
@Mapper
interface AddressMapper {
    @Mapping(source = "zipCode", target = "postalCode")
    @Mapping(source = "country", target = "countryName")
    fun toDto(address: Address): AddressDto
}
```

### 3. MapStruct KSP Generates Java Implementation

The processor generates `PersonMapperImpl.java` in `build/generated/ksp/main/java/`:

```java
@Generated(
    value = "org.mapstruct.ap.MappingProcessor",
    comments = "version: , compiler: KSP, environment: Java 17.0.15 (Azul Systems, Inc.)"
)
class PersonMapperImpl implements PersonMapper {
  @Override
  public PersonDto toDto(Person person) {
    if (person == null) {
      return null;
    }
    PersonDto personDto = new PersonDto();
    // TODO: Field mapping not yet implemented for Kotlin properties
    return personDto;
  }
}
```

Note: The `compiler: KSP` comment confirms this was generated by the KSP backend.

### 4. Use in Kotlin Code

```kotlin
val mapper = PersonMapperImpl()
val dto = mapper.toDto(Person("John", "Doe", 30))
```

## Key Technical Details

### Architecture
- MapStruct's `processor-ksp` module provides KSP backend via `MapStructSymbolProcessor`
- Uses `javax.lang.model` adapter layer to bridge KSP → MapStruct's internal API
- All existing MapStruct processors work unchanged with KSP data

### Kotlin-Specific Handling
- **Modifier handling**: Kotlin interface methods are implicitly `public abstract` but KSP doesn't set these modifiers explicitly
  - Solution: `KspKindMapper.mapModifiers()` adds PUBLIC/ABSTRACT for interface methods
  - Uses `function.isAbstract()` instead of checking `Modifier.ABSTRACT` in collection
- **Method discovery**: Uses `getAllFunctions()` instead of `getDeclarations()` to find interface methods

### Current Limitations
- Kotlin property accessors not yet recognized (MapStruct expects Java-style getters/setters)
- This causes empty mapper implementations (null checks work, but no field copying)

## Build & Run

### Build processor-ksp module (from MapStruct root):
```bash
./gradlew :processor-ksp:build -x test
```

### Build demo project:
```bash
cd ksp-demo
./gradlew clean build
```

### Verify KSP is being used:
```bash
./gradlew :sample:kspKotlin --info 2>&1 | grep MapStruct
```

Expected output:
```
i: [ksp] loaded provider(s): [org.mapstruct.ap.ksp.MapStructSymbolProcessorProvider]
i: [ksp] MapStruct KSP: Found 2 mapper(s) to process
i: [ksp] MapStruct KSP: Successfully processed mapper org.mapstruct.demo.PersonMapper
```

Generated sources are in: `sample/build/generated/ksp/main/java/org/mapstruct/demo/`

## Verification

You can verify the demo works with real MapStruct KSP processor:

1. **Check generated file comments**:
   ```bash
   cat sample/build/generated/ksp/main/java/org/mapstruct/demo/PersonMapperImpl.java
   ```
   Should contain: `compiler: KSP`

2. **Decompile to check method modifiers**:
   ```bash
   javap -p sample/build/classes/java/main/org/mapstruct/demo/PersonMapperImpl.class
   ```
   Should show: `public org.mapstruct.demo.PersonDto toDto(...)`

3. **Check JAR contains KSP classes**:
   ```bash
   jar tf ../processor-ksp/target/mapstruct-processor-ksp-*.jar | grep KspKindMapper
   ```
